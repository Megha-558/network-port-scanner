Network Port Scanner

Description

A simple Python-based tool to scan a target system and identify open and closed ports. It helps in basic network security analysis and learning cybersecurity concepts.

---

Features

- Scan ports on a target IP
- Detect open/closed ports
- Fast and easy to use

---

Tech Used

- Python
- Socket Programming
- TCP Protocol

---

How to Run

git clone https://github.com/your-username/Port-Scanner.git
cd Port-Scanner
python scanner.py
